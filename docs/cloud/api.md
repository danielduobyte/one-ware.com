# ONE WARE Cloud REST-API
See the REST Endpoints in our [interactive API documentation](https://cloud.one-ware.com/scalar/v1).

For using our REST-API you need an API-Token and exchange them for a Bearer JWT.
To exchange the API-Token for a Bearer JWT you can use our [Auth Endpoint](https://cloud.one-ware.com/scalar/v1#tag/auth/POST/api/Auth/token).

You can create an API-Key under: https://cloud.one-ware.com/Account/Security/Api-Keys

:::warning
Please notice that a JWT has an expiration date. When you use the API you need to renew the JWT before it gets expired. 
:::
